# Lab

Copy-first Biopeia Lab apparatus/application extraction candidate. The initial
slice contains small study-design and analysis utilities only; it is not a
complete Lab application and does not establish scientific results.

Included utilities validate seed pairing/disjointness and summarize scalar
study measurements. They do not run experiments, own simulated life, or carry
scientific artifacts.

## Development

```sh
python -m pip install -e '.[dev]'
python -m pytest
```

Python package and distribution name: `lab`.
